> 直方体ブロックを転がして、光るネオンゴールを目指す本格3D立体パズルゲーム。

---

## 🎮 ゲームの特徴

- **直感的なブロック転がしアクション**: 
  - 前後左右に直方体ブロックを転がし、立ち姿勢（Standing）と横倒し姿勢（Lying）を切り替えながら進みます。
  - ピボット軸回転による滑らかなアニメーションと小気味よい石の転がり音・着地音を再現。
- **全1000ステージの壮大なボリューム**:
  - 手作りの厳選クラシックステージ群に加え、逆転がりアルゴリズムにより**全ステージが100%解けることを数学的に保証**したプロシージャルステージを収録。
  - いつでも「続きから遊ぶ」自動セーブ機能に対応。
- **多様なギミックと難易度変化**:
  - 通常の床タイル、直立すると底が抜ける壊れる床（オレンジタイル）、床を架け替えるソフトスイッチ＆ヘビースイッチ。
  - 高難易度ステージでは、キューブ型（1x1x1）やロングブロック（1x1x3）など変形ブロックのパズルも登場。
- **アプリ内アップデータ搭載**:
  - アプリ内からGitHub Releasesと通信し、最新バージョンを直接確認・ダウンロード可能。
  - 3秒間のサイバーセキュリティスキャン演出、予想ダウンロード容量・改善点・新機能の表示、およびネオンダウンロードアニメーションを実装。

---

## 🕹 操作方法

| 入力 | アクション |
| :--- | :--- |
| **矢印キー (↑ ↓ ← →) / WASD** | ブロックを各方向へ転がす |
| **画面上のD-Pad (十字キー)** | モバイル・タッチ画面で直感的に操作 |
| **画面スワイプ / フリック** | 画面をスワイプしてスピーディに操作 |
| **R キー / 🔄 ボタン** | いつでもステージを最初からリトライ |
